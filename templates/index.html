How it works

Three simple steps from mammogram to report.

01

Upload a mammogram

Upload a breast X-ray (mammogram) image in JPG or PNG format. Any standard screening view works.

02

CNN analyzes it

A transfer-learning based Convolutional Neural Network (CNN) examines the mammogram and classifies it as benign or malignant.

03

Get your report

About this tool

A research-grade mammography screening studio

This application demonstrates a complete deep-learning pipeline — mammogram preprocessing, CNN training on a public breast-imaging dataset, and a production-style prediction API — wrapped in a calm, photography-first interface. It is intended for education and research only and is not a medical device.

  • Center-crop + resize to 224×224 before inference
  • MobileNetV2 transfer learning with fine-tuning
  • Data augmentation & class weighting for imbalance
  • Confidence + risk-level scoring per scan
  • Detailed downloadable clinical-style report
